# الإحصاءات والمبيعات والتنبيهات – خطوات التفعيل (مرة واحدة)

بعد هذه الخطوات تظهر في لوحة التحكم ثلاثة تبويبات: **📊 الإحصاءات**، و**💰 المبيعات**، و**🔔 التنبيهات**.

## 1) قاعدة البيانات (دقيقة واحدة)
1. افتح Supabase ← مشروعك ← **SQL Editor** ← **New query**.
2. انسخ محتوى الملف `docs/analytics.sql` كاملاً، والصقه، ثم اضغط **Run**.

بعدها يعمل تبويب **الإحصاءات** مباشرة (الزيارات والضغطات تبدأ بالوصول بعد نشر الموقع).

## 2) حساب البريد (Resend – مجاني)
1. أنشئ حساباً في **resend.com** بنفس بريدك الذي ستصله التنبيهات.
2. **API Keys** ← **Create API Key** ← انسخ المفتاح (يبدأ بـ `re_`).

ملاحظة: بدون ربط دومين، يرسل Resend إلى بريد حسابك فقط، وهذا يكفي للتنبيهات.

## 3) المفاتيح السرية في Supabase
Supabase ← **Edge Functions** ← **Secrets** ← أضف:

| الاسم | القيمة |
|---|---|
| `RESEND_API_KEY` | مفتاح Resend من الخطوة 2 |
| `SALES_WEBHOOK_KEY` | أي نص طويل عشوائي تختاره (مثل كلمة سر قوية، أحرف وأرقام فقط) |
| `PAYHIP_API_KEY` | (اختياري) Payhip ← Settings ← Developer ← API key |

## 4) الدالتان
Supabase ← **Edge Functions** ← **Deploy a new function** ← **Via Editor**، مرتين:

1. الاسم `sales-webhook`، والصق محتوى `supabase/functions/sales-webhook/index.ts`.
2. الاسم `daily-report`، والصق محتوى `supabase/functions/daily-report/index.ts`.

في إعدادات **كل دالة**: أوقف **Verify JWT** (أو **Enforce JWT verification**)، لأن Payhip وGitHub لا يسجلان الدخول.

## 5) ربط المتاجر
في لوحة التحكم ← **💰 المبيعات** ← «ربط المتاجر» تجد الرابطين. استبدل `KEY` بقيمة `SALES_WEBHOOK_KEY`:
- **Payhip**: Settings ← Developer ← Webhook URL ← الصق الرابط ← اختر **paid** و**refunded**.
- **Gumroad**: Settings ← Advanced ← Ping endpoint ← الصق الرابط ← Send test ping.

مبيعات **سكة** و**Etsy**: من زر «+ إضافة بيع يدوي».

## 6) التنبيهات
لوحة التحكم ← **🔔 التنبيهات** ← اكتب بريدك ← حفظ ← **أرسل رسالة تجريبية الآن**.

التقرير اليومي يصل كل صباح بعد الساعة 7 بتوقيت فنلندا (GitHub يشغّل الفحص كل ساعة: `.github/workflows/alerts.yml`).

## الخصوصية
- عدّ الزيارات مجهول الهوية: بدون كوكيز، وبدون عنوان IP أو اسم أو بريد. لذلك لا يحتاج الموقع نافذة موافقة على الكوكيز.
- من رسائل Payhip/Gumroad نحفظ: المنتج، والمبلغ، والرسوم، والتاريخ فقط. **لا نحفظ بريد المشتري ولا عنوان IP.**
